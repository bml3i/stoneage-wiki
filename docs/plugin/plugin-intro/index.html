关于外挂脚本

如何新建一个脚本​

  1. 点击STW外挂右下角的"脚本制作"按钮
  2. 在弹出的脚本制作窗口中，输入脚本内容
  3. 点击"保存脚本"按钮，选择保存路径，并输入密码，确定保存
关于密码

如果忘记密码，将无法查看或再次修改该脚本的内容，除非借助第三方工具。

如何查看一个脚本​

  1. 在脚本制作窗口中，点击"打开脚本"按钮，选择要查看的脚本文件(.sec格式)
  2. 输入正确密码，确认后即可查看该脚本的内容

如何修改一个脚本​

  1. 在脚本制作窗口中，点击"打开脚本"按钮，选择要查看的脚本文件(.sec格式)
  2. 输入正确密码，确认后即可查看该脚本的内容
  3. 修改脚本内容后，点击"保存脚本"按钮，选择保存路径，并输入密码，确定保存

如何调试脚本​

  1. 在脚本制作窗口中，选择要调试的代码行，或者调试的起始位置
  2. 点击右侧的"单步执行"可以执行光标当前所在的代码行
  3. 点击右侧的"执行"则可以从光标当前位置开始执行下方所有的代码行直至结束
