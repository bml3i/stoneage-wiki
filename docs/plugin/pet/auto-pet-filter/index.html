捉宠时自动扔宠

脚本介绍​

当前版本的STW外挂的捕捉宠物设置中，"丢弃不满足条件的宠物"功能无法正常使用，所以需要使用脚本的方式，定期检查并丢弃不满足特定三围的宠物。但是游戏中的宠物种类繁多，不同的宠物有不同的三围要求，所以需要根据具体的情况来设置脚本，这就需要用脚本生成器的方式让玩家提供具体的三围要求，从而生成相应的脚本，让每一位玩家都可以抓到自己满意的宠物。

使用说明​

  1. 打开 链接，填写宠物名称、1级宠物出现坐标、最低的三围，点击Submit按钮。

  2. 将生成的脚本源代码粘贴到STW外挂的脚本制作窗口中，保存为一个新的脚本。

  3. 捕捉宠物时，运行上一步骤生成的脚本，即可自动丢弃不满足三围要求的宠物。

特别提醒

服务器如果比较卡，运行该脚本有极小概率会扔掉身上不该扔掉的宠物，所以请不要携带高级或稀有宠物前去捉宠。
