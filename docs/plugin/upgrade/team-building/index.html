断线时队员自动入队

脚本介绍​

挂机时偶尔会遇到角色断线的情况，若不及时重连并重返队伍，可能因战力下降导致团灭。STW外挂支持断线自动重连功能：只需在SACH.txt文件中配置好服务器名称，即可在掉线后自动重新登录游戏，配合脚本快速回归队伍继续战斗。

使用说明​

  1. 打开 链接，填写队长位置(队长原地遇敌的坐标)，点击Submit按钮。

  2. 上面的脚本生成器程序会生成2段脚本，上部分的脚本队长运行后可以到达指定坐标，下部分的脚本队员运行后可以自动入队。将上述生成的脚本源代码分别粘贴到STW外挂的脚本制作窗口中，分别保存为2个脚本，分别命名为"队长准备"和"队员自动入队"。

  3. 挂机时，队长先运行"队长准备"脚本，到达指定坐标后，队员分别运行"队员自动入队"脚本即可自动入队。组队完成后，队长可使用"恶魔符"或"原地石"来开启原地遇敌。

特别提醒

队长位置的坐标处最好不要有其他玩家，而且要保证队长位置四周8个没有障碍物或传送点，否则入队时可能会失败。
