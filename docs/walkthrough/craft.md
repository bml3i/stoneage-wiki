## 滋润铠/滋润服

|------|------|------|
| 铠9滋润4 | 皮8 + 石8 + 百人铠 + 花8 | 钝刀: 很容易出凯8滋润3，小概率出凯9滋润4 |
| 铠10滋润4 | 百人铠 + 柯石 + 花10 |  |
| 铠/服11/12/13滋润4/5 | 胚子 + 百人铠✖️4 + 花11 <br/> 治愈铠/服11/12 + 百人铠✖️2 + 花11  | 厂长: 胚子可以这样合: <br/> (柯石 + 气瓶, 柯石 + 柯石, 铠10 + 柯石, 石10 + 柯石, 石9 + 柯石, 兜10 + 柯石) |
