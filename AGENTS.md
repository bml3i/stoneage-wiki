# AGENTS.md

Docusaurus 3.9.2 static site for the 石器时代2.5 resource wiki (content is Chinese). No backend.

## Commands

- Use **npm** (`package-lock.json` + CI use npm). README's `yarn` instructions are stale.
- Node >= 20.
- Dev: `npm start` (custom port: `PORT=3030 npm start`)
- Verify changes: `npm run build` — there is no lint/test/typecheck script. The build is the check.
- Serve built output: `npm run serve`. Clear cache: `npm run clear`.
- Manual deploy: `npm run deploy` (CI normally handles it).

## Build gotchas

- `onBrokenLinks: 'throw'` — any broken internal link fails `npm run build`. Check links before finishing.
- `blog: false` in `docusaurus.config.js`; the `blog/` directory is leftover template and is not built. Do not add blog posts there.
- Custom webpack rule in `docusaurus.config.js` treats `.sec` and `.txt` as `asset/resource`. Download links rely on it via `require('./assets/script/foo.sec')`; any new downloadable asset needs one of those extensions (or a new rule).
- `build/` is generated and gitignored; never edit it.

## Content layout

- Docs live in `docs/{plugin,faq,walkthrough,tutorial}/`; sidebars are autogenerated per folder (`sidebars.js`). Adding a `.md`/`.mdx` file is enough to add it to the sidebar.
- Control order with `sidebar_position`; group order/labels with `_category_.json` (`label`, `position`, `link.type: generated-index`).
- Typical frontmatter: `title`, `sidebar_label`, `sidebar_position`, `hide_table_of_contents: true`.
- Images are co-located under each section's `assets/img/` and embedded with MDX JSX:
  `<img src={require('./assets/img/foo.jpg').default} alt="..." style={{width: 600}} />`.
- Standalone HTML pages go in `static/` and are served at the site root.
- Site config (title, navbar/sidebar labels, URL) is in `docusaurus.config.js`; custom styles in `src/css/custom.css`.

## Deployment

- `.github/workflows/deploy-on-tag.yml` runs on tags matching `v*`: `npm ci` → `npm run build` → publishes `build/` to `gh-pages`.
- Production URL: https://stoneage.leobiblog.top (GitHub repo `bml3i/stoneage-wiki`).
